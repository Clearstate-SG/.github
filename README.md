# Technology governance

## Organization profile and repository standards

This repository publishes the Clearstate organization profile from `profile/README.md`. The product console organizes work into Surgical, IVD, company-wide secondary research, product demos, client deliveries and tech services.

Start with the [software catalog](https://github.com/Clearstate-SG/clearstate-portfolio) and its repository standards. Catalog access follows organization repository permissions. Keep this public profile generic; update `profile/README.md` on a reviewed branch to change the organization homepage.

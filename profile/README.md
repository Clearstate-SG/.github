# Clearstate

Clearstate technology supports client projects and reusable company capabilities.

- **Client Projects** — client-specific analysis, applications and deliverables.
- **Clearstate Platforms** — shared systems and reusable product infrastructure.
- **Data & Pipelines** — governed ingestion, transformation and reporting.
- **AI & Automation** — tools and workflows that support teams.
- **Sandbox / Experiments** — exploratory work with explicit status.
- **Archive / Legacy** — preserved historical work, reviewed before retirement.

Authorized Clearstate colleagues can start with the [internal software catalog](https://github.com/Clearstate-SG/clearstate-portfolio) and [repository standards](https://github.com/Clearstate-SG/clearstate-portfolio/blob/main/docs/repository-standards.md).

Use branches and reviewed pull requests, document ownership and dependencies, protect credentials and confidential data, and preserve history and access when organizing repositories.
